# Чек-лист мобильного QA (T-178)

**Статус:** базовый чек-лист и автоматические проверки готовы. Прогон на
реальных устройствах — отдельная задача **T-188** (RC-тестирование перед
публикацией в RuStore). Матрица — в
[ANDROID_RUSTORE_ROADMAP.md](ANDROID_RUSTORE_ROADMAP.md) §7.4.

## 1. Автоматическая база (уже в CI)

```bash
python -m pytest tests/test_pwa.py tests/test_cors.py -q
cd frontend && npm run test && npm run lint && npm run build
```

Проверяется:

- манифест PWA: `display: standalone`, иконки 192/512, `theme_color`;
- service worker: кэш оболочки, исключения `/api` и `/v1`;
- `index.html`: viewport, manifest, apple-touch-icon;
- CORS: dev-origin’ы и `https://app.ai-pets.ru`.

## 3. Матрица устройств (минимум)

- Android 10, 11, 12, 13, 14, 15 (эмуляторы + 2 реальных устройства).
- Оболочки: Samsung OneUI, Xiaomi HyperOS/MIUI, Honor/Huawei без GMS,
  чистый Android.
- Экраны: телефон ~5.5", телефон ~6.7", планшет 10".
- RU и EN, тёмная тема, портретная и альбомная ориентация.
